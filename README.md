# TaxMate Solutions — Client & Admin App

- **Live app:** https://app.taxmatesolutions.com (the old https://taxmate-app.vercel.app address forwards here)
- **Free tax calculator:** https://app.taxmatesolutions.com/calculator
- **Website:** https://www.taxmatesolutions.com
- **Stack:** React + Vite + Tailwind, Supabase (database, logins, storage, Edge Functions), hosted on Vercel.
- **Database changes:** `database/*.sql` (run in the Supabase SQL Editor, in date order).
- **Edge Functions:** `supabase/functions/` — `portal-admin`, `payhere`, `reminders`.

Deployment notes are kept in the project doc "TaxMate App - Deployment Guide".
